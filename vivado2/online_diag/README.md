# 800MT/s在线PRNG密集/稀疏读对照

2026-10-29新增，状态：实现及16轮上板完成，数据通过。累计读256MiB，密集/稀疏各128MiB，16根DQ全部0错、fatal0；详见[实测报告](hardware/2026-10-29_results.md)。独立工程位于build/project；沿用母板引脚、颗粒VRP107配置、1.5V/SSTL15、CK400MHz/UI100MHz及原时钟/复位模块。原vivado2工程及Flash保持。

## 流量与观测

原native_to_axi只支持单个16字节AXI事务，不能直接产生历史并发密集流量。因此本工程使用独立AXI4测试发生器，不再经过该桥。仍没有应用CPU或AXI互连。

写入1MiB，65536个16字节数据拍；写突发32拍，每次512字节，所有突发对齐且不跨4KiB边界。数据为固定seed=137A5C29、native word address相关的128bit PRNG。写入全部收到成功BRESP之后开始读取。

16遍读取交替执行：偶数遍ARLEN=31、每突发32拍连续读取；奇数遍ARLEN=0、单次16字节，两个事务之间额外100个UI周期，约1us。期间不重写。每遍65536个数据拍，单轮共1048576个读取数据拍（16MiB流量），其中密集/稀疏各8MiB，唯一地址覆盖仍是1MiB。AXI只有一个在途读请求；连续突发的32拍不等同于历史native的32个独立在途命令，结果不得直接等同原paired复现。

VIO的start默认0；通过JTAG置1后运行，结束后停在HALT。start只允许在IDLE/HALT时清零重启；发生fatal时脚本停止，不盲目重启残留AXI事务。ILA记录总体计数、16遍独立错误数、16根DQ位翻转数，以及首错byte地址/遍号/期望值/实际值。DQ映射按MIG byte-major格式，DQ=(bit//64)*8+bit%8。数据错误继续统计，协议错误、校准丢失、超时停止。

UART仍保留，每遍及最终输出512bit原始记录；其格式为本测试专用AXID/LEGS，不用旧DPIN解码器解释。在线判断和归档均使用ILA，不依赖串口连接。
