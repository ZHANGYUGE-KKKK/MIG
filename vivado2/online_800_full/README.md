# 800 MT/s 全容量在线压力测试

2026-10-29，按用户要求从1600切回800。独立BD工程，JTAG直接下载，Flash不改写。已完成全容量实测：写1GiB、读16GiB，0错、fatal0、实际峰值30，起止CAL PASS。见[报告](hardware/2026-10-29_results.md)。

## 配置和验收

- VRP107单rank x16、1 GiB，CK400 MHz、UI100 MHz、CL6/CWL5，参考250 MHz，保持原引脚、1.5V及ODT/驱动配置。
- 基于已验证的独立请求引擎，密集读上限32个单拍AXI请求，同ID顺序返回、RREADY持续响应；稀疏读最多1个请求，额外100 UI周期约1 us。
- cfg_large=0：1 MiB；cfg_large=1：完整1 GiB，即67108864个16字节数据拍。有效字节地址0x00000000–0x3fffffff；最后一个拍地址0x3ffffff0。索引和累计计数宽度覆盖该边界。
- 每轮完整写入地址相关伪随机数据，再执行16遍全区域读取，密集/间隔各8遍，交替之间不重写。大区域每轮写1 GiB、读16 GiB。
- 所有地址都写完再读，避免立即读回掩盖地址别名。数据随地址变化，但并不替代物理逐针连线或专用DM掩码测试。
- 验收同时要求：MIG实际Bit Time=1250 ps、校准PASS；正确结束；写/读计数完整；总/逐遍/逐DQ错误0；协议、超时、校准丢失fatal0；实际并发峰值记录；实现时序/DRC通过。
- 这是当前独立单拍请求引擎最高并发及全容量覆盖，不声称已达到DDR理论带宽极限；没有同时混合随机地址读写、DM掩码、全部数据模式或温度范围。
