# VCU118 → 转接板 → DDR3：完整调试链路

本文是调试主入口，记录截至本轮的已知条件、实验台账、证据边界和后续决策。详细逐次过程保留在[RESULTS](RESULTS.md)，执行状态保留在[TODO](TODO.md)。后续每次大的上板实验完成后，必须先归档原始日志、校验覆盖、统计结果、更新台账及TODO，再决定下一实验。

## 目标与当前结论

目标是验证外接DDR链路线序、地址覆盖和目标负载下的数据可靠性，并区分应用逻辑、MIG/PHY、存储器、连接器及转接板因素。

**最新800全容量压力已通过：**1GiB原PRNG整区密集/间隔对照写1GiB、读16GiB0错；互补模式连续32拍突发16轮写16GiB、读256GiB0错。累计写17GiB、读272GiB、fatal0、16个DQ均0；实际峰值分别30个单拍请求、2个32拍突发，后者端到端平均1.442GB/s。见[完整报告](../vivado2/online_800_burst/hardware/2026-10-29_results.md)。

**截至2026-10-29：800MT/s新在线测试通过，1600MT/s数据失败。** 调压后DPIN+ILA完成8320写/读0错；800AXI连续突发16轮读256MiB0错；800独立请求3次重新配置/校准、24轮读384MiB0错，实际峰值30。[800并发报告](../vivado2/online_multi/hardware/2026-10-29_results.md)。

1600独立请求实际峰值32：1MiB区域8轮读128MiB共330错拍（密集330、间隔0）；16MiB区域8轮读2GiB共3069错拍（密集3068、间隔1）。合计3399错拍，3484个bit翻转，均在DQ9/10/11，属于DQS1高字节组的DQ8–11这一半。校准保持PASS、fatal0。[1600报告](../vivado2/online_1600/hardware/2026-10-29_results.md)。错误强烈依赖负载，但不能继续说“只在密集读出错”。

此前子板实测1.33/1.33/0.66/0.66V与1.5V/SSTL15工程不一致；用户调R257重启后，进一步确认四路均符合1.50/1.50/0.75/0.75V目标。1600仍错，因此低电压不能解释全部现象。优先检查该高字节半组的高速读裕量、PHY采样及DQ/DQS信号完整性；尚不能定位到母板、转接板、子板或连接器中的唯一一处。新测试不含旧native比较FIFO，仍复现高字节错误，但不能据此绝对排除全部逻辑/约束问题。

旧native paired在800的4份VRP日志为472/317/263/436错，作为历史保留。新旧发生器/布局/供电不同，800与1600的CL/CWL及实际峰值也不同，不把对照当作严格频率单变量A/B。该阶段唯一覆盖最大16MiB；随后E22补全1GiB两种互补地址模式且通过。DM、逐针身份、混合随机读写和冷启动长期稳定性仍未验收。

## 不可忽略的硬件条件

- 母板VCU118 Rev2，xcvu9p-flga2104-2L-e；外接DDR3，不是母板DDR4。
- 母板J2 HPC1 → 无源重排转接板 → 子板J4，50信号映射见[pinmap](../EDA/pinmap.json)。
- U26 D9ZWN为MT41K512M16VRP-107 IT:P、1866MT/s档；单rank、两个4Gb x8 die组成x16、总1GiB，见[颗粒审计](part_audit/README.md)。
- 工程1.5V/SSTL15；Si570参考250MHz。800时CK400/UI100MHz，1600时CK800/UI200MHz；1600硬件报告Bit Time625ps。R257调整本地VDDQ，VTT/VREF跟随一半；用户确认调后达到目标，未逐项抄精确读数，温度/动态纹波仍无实测。
- H2移除后，完整DDR链路与JTAG可共存。原Calibration Failed时只有转接板、未接DDR核心板。用户已撤销“必须Flash下载”的旧限制，优先JTAG/VIO/ILA，UART保留。
- JTAG固定3MHz。首个ILA镜像默认频率上传曾报数据损坏，3MHz重试成功；不计为DDR读错。[在线基线](../vivado2/debug_online/README.md)、[JTAG记录](jtag_coexist/README.md)。
- LED7=BA37指示校准，不代表数据PASS；简单模式校准窗口有效，复杂校准SKIP的零值不代表零裕量。
- UART为CP2105 SCI115200/8N1，稳定ID012F60DB的if01-port0，tty编号可能变化。
- 双QSPI各128MiB。此次仅临时JTAG下载，Flash未改写；SW16保持，掉电后恢复原Flash镜像。当前保留800连续突发在线镜像，全1GiB最后一轮完成在HALT，全部事务已返回，VIO可重启。

## 已有判断及不能排除的原因

| 假设 | 当前支持/反证 | 当前处理 |
| --- | --- | --- |
| DQ9永久断路/固定接地 | DQ9多次正确读出0/1，稀疏读无错，不符合简单永久固定值故障 | 降低优先级；仍需实际导通/短路测量 |
| 固定写错后每遍稳定返回同错值 | 写一次后密集/稀疏交替，错误地址实际值变化，稀疏正确 | 不足以解释全部现象；读路径/内容稳定性优先 |
| 仅32项FIFO或最大并发造成 | 旧单笔版也曾错；新方案上限4也错 | 不能只归因32并发；检查事务和独立发生器 |
| 颗粒型号/参数完全不匹配是唯一原因 | 核对修订后仍错，且原多项等待本就保守 | 修订作为准确基线，不将“换型号”当修复结论 |
| 连接器/SI/电源/PHY采样裕量 | 与密度、模式、DQ及拍相关，具有线索 | 仍需独立证据，当前无法区分哪一处器件 |
| 自写发生器/比较逻辑或MIG交互 | UI仿真通过不覆盖PHY；物理实现变化影响也未隔离 | 继续保留，准备独立TG或片内捕获+UART |
| 高位地址混叠/容量配置 | E22全1GiB两种地址相关互补模式0错 | 本轮模式未发现稳定别名，专用标记交换及物理身份仍独立验证 |
| 预热后自然稳定 | 472→317→263→436并非单调改善，无温度记录 | 不再依据计数下降作预热推断 |
