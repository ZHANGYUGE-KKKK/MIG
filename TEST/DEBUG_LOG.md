# VCU118 → 转接板 → DDR3：完整调试链路

本文是调试主入口，记录截至本轮的已知条件、实验台账、证据边界和后续决策。详细逐次过程保留在[RESULTS](RESULTS.md)，执行状态保留在[TODO](TODO.md)。后续每次大的上板实验完成后，必须先归档原始日志、校验覆盖、统计结果、更新台账及TODO，再决定下一实验。

## 目标与当前结论

目标是验证外接DDR链路线序、地址空间覆盖和目标负载下的数据可靠性，并区分应用逻辑、MIG/PHY、存储器、连接器及转接板因素。

当前结论（更新至2026-10-26）：BD版低负载数据位测试第1份完整日志已通过，32地址×260模式，8320写/读、0错；见[实测报告](../vivado2/tests/hardware/2026-10-26_bd_dpin_run1.md)。此前压力/诊断数据测试仍存在历史失败，尚未证明其故障消失。VRP匹配配置800 MT/s的4份完整paired日志各有472、317、263、436个错突发。错误以DQ9为主，伴少量DQ8，均在DQS1高字节组；目前只在PRNG密集多笔读条件下复现。稀疏读、读上限1及全1/行走0在这4份日志中未检出错误。尚未完成全1GiB地址唯一性验证，不能认定所有地址线正确或整个转接板合格；也没有证据将故障直接归因于转接板设计。

## 不可忽略的硬件条件

- 母板VCU118 Rev2，xcvu9p-flga2104-2L-e；使用外接FMC DDR3子板，不是母板DDR4。
- 链路为母板J2 HPC1 → 无源重排转接板 → 子板J4。50根DDR信号的静态映射见[pinmap](../EDA/pinmap.json)。
- U26实物丝印D9ZWN，经美光解码为MT41K512M16VRP-107 IT:P，1866 MT/s档，单rank，两个4Gb x8 die组成x16，整体1GiB。资料核对、球位及参数修订见[颗粒审计](part_audit/README.md)。
- 本项目采用1.5V/SSTL15，Si570参考250MHz；用户确认时钟及VADJ设置已保存。800 MT/s时CK400MHz、UI100MHz，1600时CK800MHz、UI200MHz。当前没有新的子板端实测供电/温度记录。
- LED7=BA37，直接指示init_calib_complete；亮灯不等于数据PASS。
- UART为CP2105 SCI，115200/8N1，稳定设备ID为012F60DB的if01-port0；实际tty编号可能变化。
- **用户明确：JTAG与DDR链路无法共存。** JTAG只用于DDR断开时的识别和Flash烧写；DDR测试用断电接链路→Flash启动→UART采集。当前不要求更改转接板以恢复共存，不将在线窗口/ILA作为必经步骤。
- 双QSPI各128MiB，SPIx8两份文件是同一镜像的分片；选同一版本的primary/secondary，PRM不参与烧写。现有Flash启动SW16设置保持不变。

## 已有判断及不能排除的原因

| 假设 | 当前支持/反证 | 当前处理 |
| --- | --- | --- |
| DQ9永久断路/固定接地 | DQ9多次正确读出0/1，稀疏读无错，不符合简单永久固定值故障 | 降低优先级；仍需实际导通/短路测量 |
| 固定写错后每遍稳定返回同错值 | 写一次后密集/稀疏交替，错误地址实际值变化，稀疏正确 | 不足以解释全部现象；读路径/内容稳定性优先 |
| 仅32项FIFO或最大并发造成 | 旧单笔版也曾错；新方案上限4也错 | 不能只归因32并发；检查事务和独立发生器 |
| 颗粒型号/参数完全不匹配是唯一原因 | 核对修订后仍错，且原多项等待本就保守 | 修订作为准确基线，不将“换型号”当修复结论 |
| 连接器/SI/电源/PHY采样裕量 | 与密度、模式、DQ及拍相关，具有线索 | 仍需独立证据，当前无法区分哪一处器件 |
| 自写发生器/比较逻辑或MIG交互 | UI仿真通过不覆盖PHY；物理实现变化影响也未隔离 | 继续保留，准备独立TG或片内捕获+UART |
| 高位地址混叠/容量配置 | 当前1MiB尚未充分覆盖 | 下一步必须补全地址空间测试 |
| 预热后自然稳定 | 472→317→263→436并非单调改善，无温度记录 | 不再依据计数下降作预热推断 |

## 计划为何调整

1. 原计划读取在线MIG窗口或用ILA，隐含JTAG与DDR可同时连接；用户明确不成立，故调整为条件不足，研究有公开语义的内部信号+UART，或直接走独立TG/物理检查。
2. 已有4份同方案日志足以复现触发条件，继续普通重启新增信息有限，优先补地址覆盖和独立观测。
3. 1600修订镜像只为后续配置一致的速率对照准备，不作为当前优先烧写目标；旧1600 probe与800 paired方案不同，不能直接归因频率。
4. 当前800已接近本MIG实现低速边界；640配置被工具拒绝，769仅IP生成通过，未实现/上板。优先改变请求负载以定位，不承诺未经验证的更低DDR速率。

## 下一实验及实际操作

独立coverage镜像保持VRP800、250MHz参考、1.5V及全部引脚。先用单笔在途和稀疏读，验证数据位行走1/0、跨全部有效突发地址位的稀疏别名检测，再做整1GiB写完后统一读回的互补地址数据。这样可分清“在某些数据模式下可读写”和“高地址不混叠且全区可比较”两种不同证据。

先完成仿真中的地址混叠、位错误、背压和超时注入，以及实现/时序/MCS检查。DDR断开时烧写，再完全断电接DDR并启动；完整日志通过解析器确认实际地址覆盖和命令/返回计数。数据错误继续统计，协议/校准/复位/超时错误停止。
